# Mushangi's Vision - Premium Portfolio

A high-caliber developer portfolio featuring cutting-edge UI/UX interactions, built with Next.js 15.

## Key Features

- **Interactive Hero Section**: Features 3D portrait tilting, Scroll-Reactive Kinetic Outlines, and a sharp "Glitch" 3D extrusion effect on typography.
- **Fintech Particle Network**: A full-screen, responsive canvas background with glowing nodes and geometric mesh connections that react to your cursor.
- **Liquid Glass Navigation**: A premium floating header using "liquid frosted glass" effects with scroll-aware transitions and animated borders.
- **Architectural Branding**: Modern logo design featuring stacked typography and rotating SVG elements.
- **Dark/Light Mode**: Full theme support with a dedicated "Pill" style toggle system.
- **Tech Stack**: Next.js 15, React 18, Tailwind CSS, Genkit AI, and Lucide Icons.

## Deployment & Git Instructions

To push your changes to GitHub, run these commands in your project root:

1. **Initialize Git**:
   ```bash
   git init
   ```

2. **Stage your files**:
   ```bash
   git add .
   ```

3. **Commit your changes**:
   ```bash
   git commit -m "feat: complete interactive hero and premium navigation"
   ```

4. **Link to GitHub** (Replace with your repo URL):
   ```bash
   git remote add origin https://github.com/shangiy/Mushangi-s-Vision.git
   ```

5. **Push to Main**:
   ```bash
   git branch -M main
   git push -u origin main
   ```

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
